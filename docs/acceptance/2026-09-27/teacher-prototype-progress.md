# 老师原型说明：实施与验收进度

来源：`D:\下载\AI4S战略图谱原型与开发优化说明.docx`，v1.0，2026-09-26。原文共 P01–P14（含 P01B）和 A01–A17。此记录描述正在实施的版本，不能作为全部验收通过证明。

## 已实现的本地完整路径

新建研判 → 任务／领域两种草稿 → 本地任务解析 → 可编辑条件与范围冲突确认 → 保存推荐快照 → 三队按条件比较 → 引文详情／团队档案／一跳关系 → 返回与刷新恢复 → 内部跟进和公开证据导出。

- 任务默认建议领域，支持手选多领域；仅中国内地，N 默认 5、允许 1–20。
- 必要条件、偏好、排除、组织条件分开；数字、交付资源和未识别必要能力不被冒充已满足。多个已识别能力可确认“全部”或“任选”。规则仍有语言覆盖边界。
- 身份从 Java 校验现有 HttpOnly 访客 Cookie；不接受客户端提交 visitorId。研判只对创建的访客可见，不等于已经具备完整组织账号体系。
- 保存条件、证据版本、推荐和领域名称快照。重复提交去重，乐观版本锁防止多窗口覆盖。旧运行及其比较选择独立保留。
- 私有研判不写入旧的公共推荐流。已接入变更 outbox：相关证据发布或撤回生成相同条件的新结果，无关变化不重算，相同证据版本去重；新确认条件优先于后台更新。任务文字和内部备注不进入公共日报。
- 联网调查按冻结条件选择问题、团队和日期偏好，明确启动；归属及独立复核通过后才发布。进度按访客授权读取，可取消、失败项重试、重启后标为中断。部分成功推进证据版本后，仍可重试原条件的未成功部分。
- 情报观察默认显示当前访客已保存研判的变化，可打开变化前后的名单和引文；公开机构榜、类目及日报仍有独立入口。
- 我的领域报告按北京时间生成，每份选择一个领域。保存私有研判前后快照、引文及已冻结公开日报的版本；周月汇总只引用指定编号和修订的日报，缺失日期明确列出。修订、导出及历史读取不会混入实时资料，内部备注和跟进反馈不进入报告。
- 导出采用白名单，包含当时条件、推荐和引文，不含内部备注、跟进负责人及联系反馈。
- 比较采用逐条件卡片，在窄屏可展开，不要求横向滚动。关系图默认当前团队一跳，明确切换全领域，保存研判返回入口。

## 验证证据

- 新研判及相关回归：38 项后端测试通过（含新私有更新、调查和报告）；此前导航、关系搜索、一跳过滤、页面及地址兼容 19 项前端测试通过，另补预览 API 代理回归测试。TypeScript 编译与生产构建通过，保留既有大分包和 lottie eval 提示。
- 浏览器：1440、1366、320 像素检查。1366／320 包含首页进入、双草稿、确认后推荐、三队比较、引文弹窗及 Escape、刷新恢复、一跳关系与返回、团队档案与返回。1440 首轮包含前六项；完整路径需随发布版本复验。
- 使用真实本地入库的蛋白质团队及成果；没有捏造比较团队。付费调用拦截，调用数 0。
- 新一轮 320 像素通过十项浏览器路径，其中调查启动、取消和部分失败重试为明确隔离的浏览器回放，调用被拦截，不代表已验证真实提供方可用性。预览 SSH 身份通道中断及 Vite 旧模块缓存均在复验前恢复；首次失败未计为通过。
- 新数据库迁移在一致性副本上新增六张研判表；原表逐表数量和哈希未变，quick_check=ok，外键错误为空。再次运行新增表数 0。
- 后续增量增加一张私有更新表；副本逐表对账不变、外键错误为空，重复迁移新增表数 0。
- 报告阶段再新增一张私有报告表，共八张老师原型相关新表；同样完成副本对账和重复迁移。1366 与 320 新增日报、周报缺失日期及导出快照一致性验收。320 验收修复了目录未加载时提交占位领域 ID 的竞态。
- 本轮界面验收使用战略图谱 API 预览进程及现有 Java 身份服务的回环 SSH 连接；不等同于新增版本已完成公网全栈发布。
- 公网仍运行 `release.json` 中的前一中间发布，本轮新研判流程尚未部署。

## 验收口径

A01、A03、A06、A09、A11、A12、A13、A14、A15 已有相应路径或自动用例，但不能据部分测试将整项全部标为通过。A02 复杂语句覆盖、A07/A08 主张级核验信息、A10 冲突与失效、A16 全站内部资料权限仍是明确剩余工作。A13/A14 的调查发布环节采用离线回放，未运行付费采集。A15 本地快照与导出一致，尚未验收真实跨日采集修订；公开日报缺失时不会声称该日没有情报。A17 当前仅验证新研判路径，其他页面需继续检查。

专家审核必须来自实际专家反馈，不能用自动测试或模型意见替代。当前没有“专家已审定”的证据。
