## 未验证及剩余问题

1. 尚未执行真实付费联网调查；提供方认证、真实费用、网络失败恢复与新资料发布质量仍需小批量线上验证。自动付费调度继续关闭。重试最多3次，原文抓取跨任务并发不超过4，模型沿用共享并发限制。
2. 36例验证的是引用可追溯性、范围和解析一致性；未做专家盲审，不能将100%引用对应率当成推荐相关性100%。自然语言规则对未收录术语、复杂逻辑仍有边界。
3. 当前联网补充每批最多处理12个已登记科研单元，显示未覆盖数量；已有情报再分析仍是另一入口。新机构发现仍依靠官方目录补充流程。
4. 33个生命科学单元仍缺本批可发布的新成果，量子与地球科学的跨机构覆盖需要继续扩大。
5. 来源机构A/B/C分数仍未完成跨领域校准，明确独立于任务分及团队分。
6. 生产构建存在既有大分包提示；冷启动下载性能不等于热搜索性能。
7. 老版日报保持兼容读取；新完整日报的冻结由明确操作触发，未开启付费自动采集。
